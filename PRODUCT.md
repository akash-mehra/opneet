# opneet

## Platform
Responsive web app; personal study use.

## Stack
Provisional recommendation: React + TypeScript + Vite, static GitHub Pages deployment. The user can still change the stack. No backend is required for version one; a future Railway API can implement the same storage/content boundaries.

## Confirmed product truth
- Exclusively NEET UG: Physics, Chemistry, Biology. No postgraduate subjects, clinical cases, PG tests, or PG terminology.
- A personal question bank with strong practice, assessment and targeted revision flows.
- GitHub is the chosen source/hosting platform; Railway is a possible future backend.
- Actual questions and explanations will be added after reviewing old PYQs. Do not invent a published PYQ collection.
- Use original design/code/content. The Marrow investigation supplies general learning patterns, not copied branding, assets or implementation.

## First-build assumptions
- The app is named opneet and is exclusively for NEET UG.
- Phone-first responsive sessions; desktop gives more space to navigation and review.
- English content for the first version.
- Local browser persistence with export/import backups; no account or cross-device synchronization claims.
- Original demonstration questions are available in a clearly labeled sample bank; the reviewed PYQ bank starts empty.

## Core learning contract
Practice reveals explanations after checking an answer; exam mode reveals feedback only after submission. Preserve first and latest answer independently. Track guesses, flags, bookmarks and time separately. Scores derive from the current session, while revision filters use stored history. Completed attempts are immutable snapshots. Timed attempts use a deadline and survive reload; practice can pause.

## Content contract
Question identity, NEET UG subject/chapter/topic, options, correct answer, explanation, source, and review state belong to a versioned content model. Only approved, validated entries enter the reviewed bank. Sample content never masquerades as a PYQ. No predicted ranks or fabricated analytics.
